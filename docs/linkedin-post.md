A blind student can now build a LEGO robot program out of blocks, run it, and
hear exactly what the robot did — on their own, with the same blocks as
everyone else at the table.

Free, open source, and it runs in a browser with no robot needed.

Block coding has been out of reach without sight for a long time, for reasons
that were genuinely hard rather than neglected. Two things changed in 2026.
Blockly, the library a great many block editors are built on, became
keyboard-navigable and screen-reader-accessible — work co-designed with blind
and low-vision children and funded by Google's Blockly Accessibility Fund. And
LEGO publishes how to talk to the SPIKE Prime hub openly, with working example
code, so anyone can build a proper tool for it.

This joins the two together. It also includes a simulated robot that describes
what it is doing in plain sentences, so a student can find out what their
program did without watching it happen.

What it needs now is the part I cannot do myself: testing by the people it is
for. If you use a screen reader, work by keyboard, or support students who do,
I would genuinely like to hear what is awkward, unclear, or simply broken.
